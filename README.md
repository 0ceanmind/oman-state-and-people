# Oman: State and People — Interactive Revision

Made by **Faisal Albusaidi**.

An interactive, large-screen revision presentation and question bank for the university common course **Oman: State and People (UHE00111)**, covering Themes 1, 2, 3A, 3B and 4.

- **Presentation** (`index.html`): 53 slides with 3D maps and globe, live charts, timelines, flowcharts and hover details.
  - `→` / `Space` next · `←` back · `O` overview · `P` presenter notes · `F` fullscreen · `B` black screen · `Q` quiz
  - Hover any underlined item, card or 3D label for details and sources.
- **Question bank** (`quiz.html`): 242 MCQ and true/false questions with explanations, practice and timed exam modes, per-theme mastery, and a "retry my mistakes" mode.

Content follows the course text. Where outside sources differ (dates, names), the slide hover cards and quiz notes say so.

Built with plain HTML/CSS/JS and Three.js (bundled locally). No build step.
